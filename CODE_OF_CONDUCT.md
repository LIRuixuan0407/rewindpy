# Code of conduct / 行为准则

Be respectful, specific, and constructive. Technical disagreement is welcome when it focuses on evidence, tradeoffs, and the work itself.

请保持尊重、具体和建设性。围绕证据、权衡和工作本身展开的技术分歧是受欢迎的。

Harassment, personal attacks, discrimination, and publishing private data are not acceptable. Maintainers may remove violating contributions or restrict participation when needed.

骚扰、人身攻击、歧视和公开他人隐私均不可接受。维护者可删除违规内容，并在必要时限制参与。
